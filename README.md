# aidirectorat.xyz

Публично-безопасный архитектурный атлас AI-офиса Николая и рабочая
база курса OpenClaw 3–6.

## Что есть на сайте

- карта текущей и целевой архитектуры AI-офиса;
- три варианта связи Obsidian, GitHub, локального и удалённого Mac;
- launch plan с контрольными точками;
- четыре смысловые системы: автоматизации, sub-агенты, второй мозг,
  безопасность и восстановление;
- универсальный аудит из 35 проверок в 10 категориях;
- 10 ключевых архитектурных вопросов с фактами и источниками;
- карта инструментов и копируемые промпты;
- HTML-копии уроков и рабочие Markdown-чек-листы.

Прогресс аудита хранится в `localStorage` браузера отдельно для каждого
проекта. Перенос между устройствами выполняется через экспорт Markdown.

## Источник сборки

Канонические исходники находятся в локальном проекте
`A02-openclaw-architect`. Сайт собирается командой:

```bash
python3 tools/build_public_site.py
```

Production публикуется GitHub Pages из ветки `main`. В публичную сборку не
включаются внутренние пути, секреты, health-данные, runtime state и приватные
отчёты.

## Процесс изменения

1. Изменить канонические исходники в `A02-openclaw-architect`.
2. Запустить `tools/render_architecture.py`.
3. Запустить `tools/build_public_site.py`.
4. Проверить курс, ссылки, секреты и desktop/mobile UI.
5. Сделать backup текущей production-версии.
6. Скопировать `dist/` в этот репозиторий, повторить QA, commit и push.
