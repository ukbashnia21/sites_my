01
Введение: вайб-кодинг и CLI (Терминал)
📖 Теоретический блок — смотрим вместе с видеоуроком. Здесь собраны ключевые понятия, к которым можно вернуться в любой момент.
Вайб-кодинг (Vibe Coding)
Современный подход к разработке: вы выступаете не как программист, а как архитектор. Передаёте идею и логику текстом, а всю работу по написанию, тестированию и отладке кода делает ИИ-агент.
📌 Вы описываете, что хотите получить, — агент сам пишет код, исправляет ошибки и выдаёт готовый результат. Вы направляете процесс и принимаете работу.
CLI — Command Line Interface
Текстовый способ взаимодействия с компьютером или сервером. Вместо кликов мышкой — чёткие текстовые команды в Терминале.
📌 Команда mkdir new_folder мгновенно создаст новую папку. Для нейросетей Терминал — идеальная среда: чистый текстовый ввод и вывод. Агент может сам запустить скрипт, прочитать ошибку и тут же исправить её.
Markdown
Язык разметки текста с помощью простых символов: # для заголовков, - для списков, | для таблиц, ``` для кода.
📌 Нейросети обожают Markdown: он позволяет структурировать мысли без траты токенов на сложную вёрстку, а результат получается предсказуемым и легко читаемым для человека.
02
Архитектура системы — как всё связано
🗺️ Это «карта» того, как все компоненты будут взаимодействовать друг с другом после успешной настройки. Сверяйтесь с ней по ходу урока.
┌─────────────────┐ │ Claude Code │ │ (VS Code) │ └────────┬────────┘ │ SSH ▼ ┌───────────┐ ┌──────────────────┐ ┌────────────────┐ │ Telegram │───▶│ OpenClaw │───▶│ OpenRouter │ │ (Боты) │◀───│ (VPS) │◀───│ (600+ моделей) │ └───────────┘ └──────┬───┬──────┘ └────────────────┘ │ │ │ │ ┌────────────────────┐ │ └───────────▶│ OpenAI Codex ИЛИ │ │ ◀────────────│ MiniMax M3 │ │ └────────────────────┘ ┌──────┴───────┐ │ Whisper ▲ │ GroQ (free) │ │ + OpenAI ($)▼ └──────────────┘

Поток данных:

1. Claude Code (VS Code на вашем компьютере) подключается к VPS по SSH — устанавливает OpenClaw, настраивает конфиги, создаёт агентов.

2. Вы отправляете сообщение (текст или голос) боту в Telegram.

3. Если сообщение голосовое — Whisper (OpenAI или Groq) конвертирует речь в текст.

4. OpenClaw обрабатывает запрос и отправляет в основную модель — OpenAI Codex (ChatGPT) или MiniMax M3 — либо в OpenRouter (резервные/бесплатные модели).

5. Модель генерирует ответ → он возвращается вам в Telegram.

03
Покупка VPS-сервера для OpenClaw
⚡ Используйте тот же аккаунт хостинга, что и в уроке 1 (netcup / Hetzner). Просто покупаем новый, более мощный сервер специально под OpenClaw. VPN-сервер из урока 1 остаётся отдельно.
🚨 Критично: OpenClaw ставится на отдельный чистый сервер. Не на тот, где VPN, n8n или другие сервисы. Выбирайте локацию максимально близко к вашему реальному местоположению — для минимального пинга.
🚫 Сервер не должен принадлежать российской компании. Дело не в том, где физически стоит «железо» — IP у вас будет зарубежный. Дело в том, чьей компании принадлежат серверные стойки и этот IP. Российские хостеры (Aeza, Timeweb, Reg.ru и т.п.) сдают зарубежные локации, но владелец — российское юрлицо, и его диапазоны IP известны. OpenAI, Anthropic, MiniMax, Google такие диапазоны часто режут по гео или блокируют. Итог: модели то работают, то нет, бот «молчит», а причину не видно. Берите хостинг, который сам по себе — зарубежная компания.

05
Прокачка Claude Code: скиллы, MCP и 4 инструмента
🔧 Базовый Claude Code — уже мощный, но его можно «прокачать»: добавить навыки и подключить внешние инструменты. Так агент из чат-бота превращается в рабочую станцию — браузер, память между сессиями, разбивка задач, работа с Google.

Сначала разберёмся в трёх словах — чтобы не путаться дальше:

🧠 Скилл (Skill) — папка с инструкциями (Markdown), которая учит Claude Code методике или знанию. Подхватывается сам по теме запроса. Примеры: Superpowers, наш скилл с документацией OpenClaw.

📦 Плагин (Plugin) — готовый «бандл»: скиллы + команды + настройки одним пакетом из маркетплейса. Superpowers распространяется как плагин.

🔌 MCP (Model Context Protocol) — стандарт-«переходник», через который Claude Code управляет внешними сервисами: браузером, памятью, Google, задачами. Каждый MCP — отдельная программа-мост со своим набором команд. Примеры: Playwright, AgentMemory, Workspace, TaskMaster.

Шаг 1. Установка Node.js — бесплатная программа, на которой работают инструменты ниже. Они запускаются командой npx — это значит «скачать и запустить одной строкой», без ручной возни. Ставим Node.js один раз.

🍎 Инструкция для macOS

Откройте стандартный Терминал Mac (Finder → Программы → Утилиты → Терминал) и выполните по очереди:

1. Установка Homebrew:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

2. Добавляем Homebrew в пути:

echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile eval "$(/opt/homebrew/bin/brew shellenv)"

3. Установка Node.js:

brew install node

4. Пути для npm:

echo 'export PATH="$HOME/.npm-global/bin:$PATH"' >> ~/.zshrc source ~/.zshrc
🪟 Инструкция для Windows

Как открыть терминал на Windows: нажмите Win + X → выберите «Терминал (Администратор)» или «PowerShell (Администратор)». Или: нажмите Win, введите PowerShell, правой кнопкой → «Запуск от имени администратора».

Зайдите на nodejs.org и скачайте установщик .msi (LTS версия). При установке убедитесь, что включена опция «Add to PATH».

Альтернативный путь (PowerShell от имени администратора):

winget install OpenJS.NodeJS.LTS

После установки обязательно полностью перезапустите VS Code, чтобы терминал подтянул новые переменные PATH.

Шаг 2. Автономный режим (Bypass Permissions) — чтобы Claude Code выполнял команды сам, не спрашивая разрешения на каждый шаг. Без него установки ниже и установка OpenClaw (шаг 06) будут спотыкаться на постоянных подтверждениях.

Включить Bypass Permissions в VS Code
1. Откройте Настройки (Settings) VS Code. Любым из двух способов:
• Горячими клавишами: Cmd + , (запятая) на Mac / Ctrl + , (запятая) на Windows.
• Мышкой: на Mac — верхнее меню Code → Settings → Settings; на Windows — File → Preferences → Settings. Или нажмите шестерёнку ⚙️ в левом нижнем углу окна → Settings.

2. В строке поиска вверху Настроек введите Claude Code.
3. Найдите пункт Claude Code: Allow Dangerously Skip Permissions и поставьте галочку.
4. Вернитесь в чат с агентом → нажмите на название режима в правом нижнем углу окна чата → выберите Bypass permissions.
🔁 Запомните, где переключается режим. Bypass Permissions нужно держать включённым каждый раз, когда даёте агенту установочные промпты. Переключатель — в правом нижнем углу окна чата с агентом. Если агент вдруг снова начал спрашивать подтверждения — проверьте, что там стоит Bypass permissions.

06
Автоматическая установка OpenClaw на сервер
🤖 Прокачанный Claude Code (с включённым Bypass Permissions) сам подключится к серверу и установит OpenClaw. Вам нужно только отправлять промпты и подставлять свои данные.

Сначала — ещё одна прокачка Claude Code. Ставим наш скилл openclaw-docs: это полная документация OpenClaw прямо внутри Claude Code. С ним агент не выдумывает команды и параметры конфига, а ставит и настраивает OpenClaw строго по официальной доке. Сделайте это до установки — дальше будет в разы меньше ошибок.

Организация работы в Telegram: группа с топиками
💡 Вести диалог с агентом в одном длинном чате — верный путь к хаосу: контексты смешаются, агент будет путать код с рецептом пирога. Правильный подход — создать Telegram-группу, включить в ней Топики (Темы) и общаться с ботом там. Каждая тема — изолированная сессия.
Создать группу и включить Темы
1. Создайте новую группу в Telegram (например, «Мой Агент»)
2. Настройки группы → Изменить → включите Темы (Topics)
3. Добавьте в группу вашего бота
Узнать chat_id группы
Добавьте в группу бота @userinfobot — он сразу пришлёт chat_id вашей группы (число с минусом, например -100123456789). Скопируйте ID и удалите бота из группы.
Узнать свой user ID
Напишите боту @userinfobot в личку — он пришлёт ваш числовой ID (просто число, без минуса). Сохраните его — понадобится для конфига.
Отключить Privacy Mode у бота в @BotFather
Идём в @BotFather → /mybots → выбрать бота → Bot Settings → Group Privacy → Turn off. Без этого бот не будет видеть сообщения в группе.
Назначить бота Администратором группы
Настройки группы → Администраторы → добавьте вашего бота → включите все права (Change Group Info, Delete Messages, Ban Users, Invite Users via Link, Pin Messages, Manage Topics, Manage Video Chats, Add New Admins). Remain Anonymous — выключено.
⚠️ Частые ошибки, которых нужно избежать:
• НЕ путай group ID (начинается с -100...) и user ID (просто число) — это разные поля в конфиге
• Group ID идёт в groupAllowFrom, User ID идёт в allowFrom
• Если забыть добавить user ID в allowFrom — бот будет отвечать «not authorized»
• Privacy Mode должен быть отключён в @BotFather (см. чекбокс выше)
